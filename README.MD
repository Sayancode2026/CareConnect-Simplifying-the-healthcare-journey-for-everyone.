# E-Healthcare Management System

## About This Project

Welcome to the **E-Healthcare Management System**, your smart solution for seamless patient care! This system is designed to simplify patient management by harnessing the power of machine learning to predict medical specialties and recommend the best hospitals nearby.

With user-friendly appointment scheduling, real-time bed availability checks, and emergency ambulance booking, this project aims to make healthcare more accessible and efficient. Collaborating with a dynamic development team, we’ve integrated APIs and constantly refined the experience based on real user feedback to ensure it’s intuitive and reliable.

Join us in transforming healthcare management with technology!

## Features

- Easy patient registration and secure login
- Intelligent appointment scheduling with specialty predictions
- Tailored hospital recommendations based on your location and needs
- Real-time bed availability monitoring
- Quick emergency ambulance booking
- API access to hospital and specialty data for seamless integration

## Technologies Used

- Python & Flask for backend and web routing
- Pandas for data handling
- Scikit-learn powering the machine learning predictions
- Clean HTML/CSS templates for a smooth user experience

## Getting Started

1. Clone the repo  
2. Install dependencies: `pip install -r requirements.txt`  
3. Add your CSV data files inside the `data/` folder  
4. Run the app with `python app.py`  
5. Open your browser at `http://localhost:5000` and explore!
